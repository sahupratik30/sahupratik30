<h2>🧠 Engineering Philosophy</h2>
<ul>
  <li>Build for users first — performance and clarity matter</li>
  <li>Prefer simple, predictable abstractions over clever ones</li>
  <li>Design components to be reusable, composable, and testable</li>
  <li>Optimize only after measuring, not guessing</li>
  <li>Write code that teammates (and future-me) can understand</li>
</ul>
